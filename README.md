# make-shorts

כלי ל-Claude שהופך פודקאסט או סרטון ארוך לקליפים קצרים ואנכיים (רילס, שורטס, טיקטוק) עם כתוביות בעברית.

אתם נותנים קישור ליוטיוב או קובץ מהמחשב. Claude מתמלל, בוחר את הרגעים החזקים, מראה לכם אותם לאישור, וחותך קליפים עם כתוביות.

## התקנה

צריך את Claude Code: את אפליקציית Claude למחשב (לשונית Code) או את Claude Code בטרמינל.

ב-Claude Code כותבים:

```
/plugin marketplace add itielbru/make-shorts
/plugin install make-shorts@make-shorts
```

אחרי ההתקנה כותבים ל-Claude: **"תעשה לי שורטים"**.

בפעם הראשונה Claude:
- בודק מה חסר במחשב (ffmpeg, yt-dlp ועוד) ומציע להתקין. כל התקנה רק באישור שלכם.
- שואל כמה שאלות על הסגנון שלכם.
- מסביר איך לפתוח חשבון חינמי ב-[Groq](https://console.groq.com), השירות שמתמלל את הדיבור. הוא פותח לכם קובץ, ואתם רק מדביקים בו את המפתח ושומרים. **אל תשלחו את המפתח בצ'אט.**

## שימוש

1. כותבים: "תעשה לי סרטונים מזה" ומדביקים קישור, או נותנים נתיב לקובץ.
2. מחכים כמה דקות לתמלול ולבחירת הרגעים.
3. מאשרים את רשימת הקליפים, מורידים חלק או מבקשים עוד.
4. מחכים לרינדור, בערך דקה-שתיים לכל קליף.
5. הקליפים מחכים בתיקייה, עם קובץ כתוביות והצעה לטקסט לפוסט.

אחר כך אפשר לבקש שינויים במילים פשוטות: "קליף 3 ארוך מדי", "כתוביות גדולות יותר", "תמצא עוד קליפים", "המילה הזאת לא נכונה".

## טיפים

- עדיף סרטון ב-1080p. ממקור באיכות נמוכה התמונה נראית מרוחה אחרי החיתוך האנכי.
- להוריד מיוטיוב רק תוכן שלכם או שיש לכם זכויות עליו.
- אם משהו נראה לא טוב, אמרו ל-Claude באיזה קליף ובאיזו שנייה, והוא ישווה את הקליף למקור ויבדוק.
- נבדק על Windows 11.
