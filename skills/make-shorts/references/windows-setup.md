# הקמה ב-Windows

## Python
- הפקודה `python` ב-Windows היא לעיתים רק קיצור שפותח את חנות Microsoft ולא תוכנה אמיתית. אם `python --version` לא מדפיס מספר גרסה, חפש Python אמיתי ב-`%LOCALAPPDATA%\Programs\Python\Python3*\python.exe`.
- אם אין Python, הסבר למשתמש מה זה ובקש אישור לפני התקנה: `winget install --id Python.Python.3.12 --exact`.
- הסקריפטים משתמשים בספרייה הסטנדרטית בלבד, ולכן אין צורך בחבילות נוספות.

## כלים נוספים (winget)
| כלי | פקודה | למה |
|---|---|---|
| ffmpeg (גרסה מלאה) | `winget install --id Gyan.FFmpeg --exact` | חיתוך, הרכבה וצריבת כתוביות. הגרסה המלאה כוללת את libass |
| yt-dlp | `winget install --id yt-dlp.yt-dlp --exact` | הורדה מקישור |
| Deno | `winget install --id DenoLand.Deno --exact` | יוטיוב דורש תוכנה שמריצה JavaScript |

אחרי התקנה הכלים עשויים לא להופיע בחלון הנוכחי. תיקון: לפתוח חלון חדש, או לרענן את `PATH` מהמערכת.

עדכון yt-dlp, כשהורדה נכשלת בשגיאה 403: `winget upgrade --id yt-dlp.yt-dlp`, אחרי אישור המשתמש.

## נתיבים עם עברית ורווחים
תיקיית הפרויקט יכולה להכיל עברית ורווחים. הסקריפטים מפעילים את ffmpeg מתוך תיקיית עבודה עם שם באנגלית, כך שהנתיב לא מגיע למסנן הכתוביות. אל תעקוף זאת בהרצה ידנית של ffmpeg.

## מפתח Groq
- יוצרים אותו באתר של Groq (חשבון חינמי). המשתמש יוצר אותו בעצמו, ואתה לא יוצר חשבונות עבורו.
- שומרים אותו בקובץ `.env` בתיקיית ההגדרות `~/.config/make-shorts/` בשורה `GROQ_API_KEY=...`. המשתמש מדביק אותו בקובץ בעצמו. אל תבקש אותו בצ'אט.

## דברים שעוד לא נמדדו (פריטי קבלה פתוחים)
- האם Groq מחזיר חותמות זמן לכל מילה בעברית (ללא זה כל החיתוכים והכתוביות מקורבים, והדוח יזהיר על כך).
- האם המילים ש-Groq מחזיר כוללות פיסוק. אם לא, הקוד משחזר אותו מטקסט הקטעים (`merge_punctuation`), אבל זה נבדק רק מול תשובות מדומות. אם גם זה לא עובד, גבולות המשפט נקבעים רק לפי הפסקות בדיבור.
- המגבלות החינמיות המדויקות של Groq.
- תמלול מקומי במחשב: מתוכנן להמשך.
